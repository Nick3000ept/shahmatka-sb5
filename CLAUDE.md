# СБ5 · Шахматка — Административная панель

## Стек
- **Frontend**: `index.html` — один файл, чистый HTML/CSS/JS, без фреймворков
- **Backend**: `script.gs` — Google Apps Script standalone, деплоится через clasp
- **Хостинг**: GitHub Pages — `https://nick3000ept.github.io/shahmatka-sb5/`
- **Репозиторий**: `https://github.com/Nick3000ept/shahmatka-sb5`

## Деплой (выполняется сразу после завершения правок)
```bash
cd "d:/YandexDisk/VS_hub/СБ5_шахматка"
# 1. Google Apps Script (бэкенд)
clasp push --force
clasp deploy --description "СБ5 vN"
# Новый deploymentId вставить в index.html (BASE=) и снова clasp push --force
# 2. Git + GitHub Pages
git add index.html script.gs appsscript.json CLAUDE.md .gitignore
git commit -m "описание изменений"
git push
```

> **Важно:** каждый новый `clasp deploy` создаёт НОВЫЙ deploymentId. После деплоя нужно обновить BASE в index.html на новый URL и сделать ещё один clasp push + git push.

## Поручения (панель «📌 Поручения», 2026-08-10)

Перенесено из СБ3. Отдельная сущность, не путать с панелью «📋 Протокол» (журнал
комментариев к работам, лист «Протокол»).

- **Лист «Поручения»**: `A=id | B=Подрядчик | C=Текст | D=Срок | E=Статус (открыто/выполнено) |
  F=Создано | G=Автор | H=Комментарий | I=Приоритет ('' | Высокий)`. Создаётся сам при первом
  открытии панели (`ensureTasksSheet_`). Столбец B сейчас фронтендом не заполняется — задел на будущее.
- **Эндпоинты**: GET `getTasks` (открытые; `&all=1` — включая выполненные),
  POST `addTasks` (пакет одним `setValues` — либо весь, либо ничего), POST `updateTask`
  (статус/текст/срок/комментарий/приоритет по id). Оба POST требуют `pwd` = пароль админа.
- **Панель видна всем**: не-админ (просмотр, подрядчик, СК) только читает список — без формы
  создания, без правки комментариев и кнопок (форма под классом `admin-only`, элементы
  управления в `taskItemHtml` рисуются только при `IS_ADMIN`).
- **Пароль админа** хранится в `sessionStorage` (`sb5_admin_pwd`) и уходит в каждый POST;
  если админ вошёл в старой вкладке и пароль не сохранён — панель попросит войти заново.
- **Форма**: «Тема» (input) + «Описание» (textarea, авторасширяется). Кнопка «＋ Добавить» —
  optimistic UI: поручение появляется в списке сразу (временный id `tmp…`), запрос уходит
  фоном, `loadTasks` подменяет запись настоящей; при ошибке — откат и возврат текста в форму.
- **Приоритет**: значок «!» в углу карточки — обычный ↔ «Высокий» (столбец I). Высокие
  наверху списка, красная полоса слева. У не-админа значок виден только у высоких, не кликабелен.
- **Выполненные** грузятся с сервера только при первом раскрытии блока «Выполнено ▸».
- **Кэш**: открытые поручения — в localStorage (`sb5_tasks`), панель показывает их мгновенно,
  свежий список тянется фоном. Все запросы — через `fetchJson` (3 попытки, распознаёт
  HTML-ответ GAS вместо данных).
- **Не перенесено из СБ3** (решение пользователя 2026-08-10): формирование протокола,
  предпросмотр, печать в PDF, рассылка подрядчикам почтой и в Telegram.
- Панели справа взаимоисключающие: открытие «Поручений» закрывает «Аналитику» и «Протокол», и наоборот.
